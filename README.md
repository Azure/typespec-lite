# typespec-rplite

This repo contains Typespec templates specifically for RP Lite partners. These templates are intended to help partners quickly set up a minimal TypeSpec project.

For more information about RP Lite, see [this page](https://eng.ms/docs/products/arm/rpaas/rp-lite/srt_overview).  
For guidance on getting started with Typespec, see [this page](https://eng.ms/docs/products/one-inventory/overview/partnerguidance/onboarding/rpplatform/typespecgettingstarted).

## Templates

There are two templates available for RP Lite partners [(these are also explained on the public facing docs)](https://eng.ms/docs/products/arm/rpaas/tsg/rpaas/rponboarding/rplitetypespectemplates):

1. Azure Resource Manager Service Project with only Operations Resource Type (arm-operations)
* This project contains a minimal TypeSpec project that models only the operations type.
2. Azure Resource Manager Service Project for RP Lite RPs (arm-alltypes)
* This project includes multiple example resource types to serve as patterns: proxy resources, location-scoped resources, extension resources, and tenant-level resources.
